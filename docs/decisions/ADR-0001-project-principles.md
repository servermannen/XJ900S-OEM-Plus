# ADR-0001: Project Principles

**Purpose:** Record the accepted principles that guide the XJ900S OEM+ project.

**Status: Accepted**

## Context

The project requires a durable basis for evaluating future requirements,
research, proposals, and implementation work.

## Decision

The project adopts these principles:

- Project vision: Diversion 2027.
- Use an OEM+ approach.
- Use staged implementation.
- Give reliability, safety, and serviceability priority.
- Prefer proven production components.
- Use custom development where it provides clear value.
- Retain important decisions and their supporting reasoning.

## Consequences

Future documentation must distinguish evidence from assumptions and preserve
the reasoning behind accepted decisions.
