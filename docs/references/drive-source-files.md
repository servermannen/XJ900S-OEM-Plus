# Project source files in Google Drive

Document status: Draft

## Storage and scope

[Project source folder](https://drive.google.com/drive/folders/1hV4T_vmlc9yTzIPMfHOOUHaYjU-RQ-05)

GitHub holds the engineering documentation and decisions. Google Drive holds copies of the source files uploaded to the ChatGPT project **OEM+ XJ 900 s**. The original ChatGPT files were retained. Drive permissions were not expanded; these links require authorized access.

Transfer date: 2026-09-23. All 21 files in the project Sources list were copied (9 manual PDFs, 9 images, 1 unclassified scanned PDF and 2 text files). File names, byte sizes, MIME types and destination folders were checked against Drive metadata after upload.

No CAD exports or separately identified measurement files were present in that Sources list. This inventory does not cover attachments embedded only in individual conversations. The scanned PDF and text files below have not been technically classified. Copying a file does not establish its technical accuracy or applicability to the motorcycle.
