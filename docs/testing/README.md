# Testing

**Purpose:** Organize project test strategies, test plans, procedures, and
recorded verification results.

## Testing guidance

Safety-critical testing shall be planned, reviewed, and performed in controlled
stages. Execution status and result classification shall remain separate.

Do not treat successful power-on, engine start, or brief operation as complete
validation.
